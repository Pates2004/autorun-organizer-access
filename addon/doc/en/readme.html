Autorun Organizer Access 1.2.0

This English-only add-on provides complete keyboard access to the classic Autorun Organizer 6.x interface. It has been directly tested with Autorun Organizer 6.32 and rejects the redesigned 7.x interface.

Commands

All 22 commands are always visible under NVDA menu → Preferences → Input Gestures → Autorun Organizer Access. Their assigned keys are active only while Autorun Organizer 6.x has focus.

  • NVDA+Alt+L: focus the startup item list.
  • NVDA+Alt+F: focus search.
  • NVDA+Alt+1, 2, or 3: Important, All, or Custom view.
  • NVDA+Alt+4: open the startup locations menu.
  • NVDA+Alt+S: enable or disable the selected startup item.
  • NVDA+Alt+C: open all commands for the selected startup item.
  • NVDA+Alt+N: toggle notifications about new startup items.
  • NVDA+Alt+Shift+N: open the notification center.
  • NVDA+Alt+A: open the Application tab.
  • NVDA+Alt+B: open the Boot time tab.
  • NVDA+Alt+Shift+B: toggle measuring every system load time.
  • NVDA+Alt+D: read the selected item and current-tab details.
  • NVDA+Alt+M: open Settings and commands.
  • NVDA+Alt+U: open Undo changes.
  • NVDA+Alt+H: report the default commands.

The following commands have no default gesture and can be assigned in Input Gestures: open reviews, toggle the interface theme, open Background functions, focus Reboot and measure, and focus the disable and delay frequency button.

Keyboard access

The selected-item command opens Autorun Organizer's standard context menu, which exposes all actions supported for that entry. Enter and Space activate virtual switches, clickable labels, startup-type group buttons, and icon controls. Arrow keys select options on the filter and details-tab virtual controls.

Sciter elements are activated by positions relative to their current control rectangles rather than fixed screen coordinates. Only 6.32 has been directly regression-tested, but all classic 6.x product versions are accepted.
