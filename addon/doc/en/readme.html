Autorun Organizer Access 1.3.2

This add-on provides complete keyboard access to the classic Autorun Organizer 6.x interface. It has been directly tested with Autorun Organizer 6.32 and rejects the redesigned 7.x interface.

Language

Open NVDA Settings → Autorun Organizer Access. Choose the Windows display language (default), English, Polish, or the Autorun Organizer language. Polish Windows or an active Polish application translation selects Polish; unsupported languages fall back to English.

The setting controls add-on messages and application captions spoken by NVDA or shown in braille. It cannot change text drawn visually inside Autorun Organizer. Reopen an already displayed application menu or dialog after changing the setting.

The startup-item action

Autorun Organizer's Sciter switch does not expose its current state. It is therefore presented as the action button Enable or disable the selected startup item, not as a check box with the false state “unchecked”. After activation, NVDA explains that the resulting state is unavailable.

The classic popup menu uses its native MSAA provider, just as it does when the add-on is disabled. NVDA therefore preserves the real checked state of commands such as Disable. The add-on translates the caption without replacing the menu item's role or state.

Disable is a checkable command, not a command whose caption changes to Run. Checked means that the selected entry is disabled at startup; unchecked means that it remains enabled.

Commands

All 22 commands are visible under NVDA menu → Preferences → Input Gestures → Autorun Organizer Access. Assigned keys are active only while Autorun Organizer 6.x has focus.

  • NVDA+Alt+L: focus the startup item list.
  • NVDA+Alt+F: focus search.
  • NVDA+Alt+1, 2, or 3: Important, All, or Custom view.
  • NVDA+Alt+4: open the startup locations menu.
  • NVDA+Alt+S: enable or disable the selected startup item.
  • NVDA+Alt+C: open all commands for the selected startup item.
  • NVDA+Alt+N: toggle notifications about new startup items.
  • NVDA+Alt+Shift+N: open the notification center.
  • NVDA+Alt+A: open the Application tab.
  • NVDA+Alt+B: open the Boot time tab.
  • NVDA+Alt+Shift+B: toggle measuring every system load time.
  • NVDA+Alt+D: read the selected item and current-tab details.
  • NVDA+Alt+M: open Settings and commands.
  • NVDA+Alt+U: open Undo changes.
  • NVDA+Alt+H: report the default commands.

Five additional commands have no default gesture: reviews, interface theme, Background functions, Reboot and measure, and disable/delay frequency.

Limitations

Enter and Space activate virtual action buttons, clickable labels, group buttons, and icon controls. Arrow keys select options on virtual filters and detail tabs. Sciter elements are activated by positions relative to their current control rectangles.

The add-on can translate only text that the application exposes through UI Automation or MSAA. Text painted solely inside Sciter, unusual dynamic server content, the visible interface, and NVDA's own role words remain outside its control.
