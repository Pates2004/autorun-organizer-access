Autorun Organizer Access 1.1.0

This add-on labels inaccessible Sciter controls and adds direct keyboard commands for the classic Autorun Organizer 6.x interface.

Commands

Every command below has a description and is registered in the “Autorun Organizer” category. Its gesture can be changed or removed in NVDA menu → Preferences → Input Gestures → Autorun Organizer, without editing the add-on files.

  • NVDA+Alt+L: focus the startup item list.
  • NVDA+Alt+F: focus search.
  • NVDA+Alt+1, 2, or 3: Important, All, or Custom view.
  • NVDA+Alt+S: toggle the selected startup item.
  • NVDA+Alt+N: toggle Autorun Organizer notifications.
  • NVDA+Alt+A: Application details tab.
  • NVDA+Alt+B: Boot time tab.
  • NVDA+Alt+D: read available details for the selected item.
  • NVDA+Alt+H: report add-on commands.

On a filter or detail-tab Sciter panel, use the arrow keys to choose an item and Enter or Space to activate it. Enter and Space also activate Sciter toggles.

Tested with Autorun Organizer 6.32 and NVDA 2026.1.1. Version 7.0 uses a redesigned interface and is outside this add-on's scope.
