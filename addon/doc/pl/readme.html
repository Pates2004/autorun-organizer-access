Autorun Organizer Access 1.3.2

Dodatek zapewnia pełną obsługę klawiaturą klasycznego interfejsu Autorun Organizer 6.x. Został bezpośrednio przetestowany z wersją 6.32 i odrzuca przeprojektowany interfejs 7.x.

Język

Otwórz Ustawienia NVDA → Autorun Organizer Access. Wybierz język systemu Windows (domyślnie), angielski, polski lub język Autorun Organizer. Polski system lub aktywne polskie tłumaczenie programu wybiera polski; nieobsługiwane języki przechodzą na angielski.

Ustawienie steruje komunikatami dodatku i nazwami programu odczytywanymi przez NVDA lub wyświetlanymi w brajlu. Nie zmienia napisów widocznych w Autorun Organizer. Po zmianie języka otwórz ponownie widoczne menu lub okno programu.

Działanie dotyczące wpisu autostartu

Przełącznik Scitera nie udostępnia bieżącego stanu. Jest więc przedstawiany jako przycisk Włącz lub wyłącz wybrany element autostartu, a nie jako pole wyboru z fałszywym stanem „nieoznaczone”. Po aktywacji NVDA wyjaśnia, że wynikowy stan nie jest dostępny.

Klasyczne menu kontekstowe korzysta z natywnego interfejsu MSAA, tak samo jak po wyłączeniu dodatku. NVDA zachowuje dzięki temu rzeczywisty stan zaznaczenia pozycji takich jak Wyłącz. Dodatek tłumaczy napis bez zastępowania roli ani stanu pozycji menu.

Wyłącz jest poleceniem przełączanym, a jego nazwa nie zmienia się na Uruchom. Stan zaznaczony oznacza, że wybrany wpis jest wyłączony w autostarcie; stan niezaznaczony oznacza, że wpis pozostaje włączony.

Polecenia

Wszystkie 22 polecenia są widoczne w menu NVDA → Ustawienia → Zdarzenia wejścia → Autorun Organizer Access. Przypisane klawisze działają tylko w Autorun Organizer 6.x.

  • NVDA+Alt+L: lista elementów autostartu.
  • NVDA+Alt+F: wyszukiwarka.
  • NVDA+Alt+1, 2 lub 3: widok Najważniejsze, Wszystkie lub Niestandardowe.
  • NVDA+Alt+4: menu lokalizacji autostartu.
  • NVDA+Alt+S: włącz lub wyłącz wybrany element.
  • NVDA+Alt+C: polecenia wybranego elementu.
  • NVDA+Alt+N: przełącz powiadomienia o nowych elementach.
  • NVDA+Alt+Shift+N: centrum powiadomień.
  • NVDA+Alt+A: zakładka Aplikacja.
  • NVDA+Alt+B: zakładka Czas uruchamiania.
  • NVDA+Alt+Shift+B: przełącz pomiar każdego uruchomienia.
  • NVDA+Alt+D: odczytaj szczegóły.
  • NVDA+Alt+M: Ustawienia i polecenia.
  • NVDA+Alt+U: Cofnij zmiany.
  • NVDA+Alt+H: podaj domyślne polecenia.

Pięć dodatkowych poleceń nie ma domyślnego skrótu: recenzje, motyw interfejsu, Funkcje w tle, Uruchom ponownie i zmierz oraz częstotliwość wyłączania/opóźniania.

Ograniczenia

Enter i spacja aktywują wirtualne przyciski akcji, klikalne etykiety, przyciski wyboru i ikony. Strzałki wybierają opcje wirtualnych filtrów i zakładek. Elementy Scitera są aktywowane według położenia względnego.

Dodatek tłumaczy tylko tekst udostępniony przez UI Automation lub MSAA. Tekst namalowany wyłącznie w Sciterze, nietypowe treści dynamiczne, widoczny interfejs i nazwy ról samego NVDA pozostają poza jego kontrolą.
